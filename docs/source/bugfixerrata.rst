Bug Fixes
=========

Bug fixes are rolled up into later releases. So a ViciBox v.13.0.1 system does not need any of the updates listed for ViciBox v.13.0.0. You only need to apply updates that are equal to or greater than your ViciBox install media version.

The version of ViciBox used to install the server is shown just above the **#** command prompt after logging in as ``root``, I.E. **- ViciBox v.13.0.0**. It is also in ``/etc/vicibox-version``. Most of the fixes are done through the CLI by logging in as the root user. This can be done over SSH or through a directly attached keyboard and monitor.

As a general rule the fixes are mainly for issues that can't reasonably be applied through a standard package update. The following sections are separated by ViciBox version and then the specific issue.

The bug fixes for ViciBox 12.0 and 11.0 are in their own manuals; see :ref:`previous-manuals`.

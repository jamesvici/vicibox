Standard ISO
============

:download:`Standard Installation Image <https://download.vicidial.com/iso/vicibox/server/ViciBox_V13.x86_64-13.0.0-beta4.iso>`
    The 'standard' version is for installation into a system with a single drive. It's the ideal option if you have a Hardware RAID, a Network or SAN you boot from, or are using a VM Guest for install. It's also the least involved to setup since it lacks the MD software RAID.

    MD5 checksum: `ViciBox_V13.x86_64-13.0.0-beta4.md5 <https://download.vicidial.com/iso/vicibox/server/ViciBox_V13.x86_64-13.0.0-beta4.md5>`__ (see :ref:`media-verify`)

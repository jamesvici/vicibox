Phase 1.5
=========

Before ViciDial is installed and set up on the servers, it is necessary to configure the network. Since this is a convenient stopping point, it is also a good time to do other things like install updates and finish the software RAID. It's recommended to do all of these where possible. Everything in this phase is done from the :ref:`manager`. The first root login already offers the network setup, updates and the RAID mirror (see :ref:`phase1`); the pages here cover doing them later or again.

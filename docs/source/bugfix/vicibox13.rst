ViciBox 13.0
============

This section contains bug fixes, errata, and patch notes related to the ViciBox v.13.0 release. You only need to run the fixes that apply to your version or newer. For example, if you are running ViciBox v.13.0.1, you only need to run the fixes for v.13.0.1 and later, not the fixes for v.13.0.0.

There are no known issues with ViciBox v.13.0 that need a manual fix. Most fixes reach ViciBox |release| as package updates, so keep the server updated (see :ref:`updates`).
